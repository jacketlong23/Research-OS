# Research OS · 科研驾驶舱

> 一个面向科研工作的智能时间规划器:以**今日安排**为主界面,以**本周课表**为辅助,
> 根据任务耗时、截止时间、重要性和项目优先级自动安排 09:00–20:30 的科研时间,
> 并记录实际完成情况,为每周复盘和半月报提供依据。

设计构想见 [Research_OS_科研驾驶舱设计构想(1).md](./Research_OS_科研驾驶舱设计构想(1).md)。

## 功能

- **今日(默认首页)**
  - Today's Big 3:今天最应该做的三件事(按截止紧迫度、重要度、阻塞关系、项目优先级评分)
  - 09:00–20:30 时间轴:当前时间线、当前/下一任务、剩余可用时间
  - 新增任务:手动表单,或一句话「导师让我明天下午之前做一个结果图,大约 1 小时」自动解析
  - 智能重新安排:一键重排未来的弹性任务(已过去的时间块永不移动)
- **本周**:周一至周日课程表视图;拖拽时间块跨天移动;固定事件(组会/课)与 Deadline 旗标
- **任务/项目**:任务全字段编辑(耗时/截止/重要度/可拆分/阻塞);项目进度卡
- **复盘**:今日/本周/半月完成统计、最近 15 天投入、每日三行记录、半月报草稿生成
- **设置**:工作时间、排程密度、AI 配置、数据导出/导入

## 排程规则(确定性规则,不依赖 LLM)

```
Score = 0.30×Urgency + 0.25×Importance + 0.20×DeadlineRisk + 0.15×Blocking + 0.10×ProjectPriority
```

- 围绕固定事件计算空闲时间块,每日弹性任务总量 ≤ 78%(可调)可用时间
- 深度工作块 90–150 分钟,任务间缓冲 15 分钟
- 不可拆任务优先保证连续整块,放不下顺延次日并给出超期警告
- 新任务增量插入:只填空隙,不打乱已有安排

## 技术栈

React 18 + TypeScript + Vite · Tailwind CSS v4 · zustand(localStorage 持久化) · react-router-dom(HashRouter) · Vitest

AI 为可选增强(OpenAI 兼容接口,默认 DeepSeek):自然语言建任务、优先级解释、半月报草稿。
**不配置 API Key 时全部功能自动降级,不影响使用。**

## 开发

```bash
npm install
npm run dev        # 本地开发
npm test           # 排程引擎单元测试
npm run build      # 产物在 dist/
```

## 数据

全部数据保存在浏览器 localStorage(5 个独立 key:projects / tasks / schedule / daily_logs / settings),
建议定期在「设置 → 数据」导出 JSON 备份。

## 部署

push 到 `main` 自动触发 GitHub Actions:测试 → 构建 → 发布到 GitHub Pages。
